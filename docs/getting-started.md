# Getting Started with SimpleLog

This guide walks you through the core workflow: install, create entries,
review totals, generate reports, and sync across devices.

## 1. Install

SimpleLog distribution is via desktop binaries and mobile app stores.

- Desktop: download the package for your OS (Windows/macOS/Linux).
- Mobile: install from the available app store release.

## 2. First Launch

On first open:

- SimpleLog creates a local database on your device.
- You can start logging immediately.
- No cloud account is required.

## 3. Add Your First Flight

Before logging flights, you need at least:

- One aircraft type
- One aircraft

You can create both directly from the New Flight flow if they do not exist yet.

1. Open `Flights`.
2. Tap `+` (new entry).
3. Fill minimum fields:
   - Aircraft type
   - Aircraft
   - Date
   - Departure airport + time
   - Arrival airport + time
4. Tap `Calculate`.
5. Review calculated values (Night, IFR, PIC/SIC, etc.).
6. Tap `Save`.

## 4. Add Simulator / Duty / Positioning

Use the same logbook flow and select the correct event type:

- Flight
- Simulator
- Duty period
- Positioning

## 5. Use Filters

Use the top filter bar to narrow data quickly:

- From / To date
- Event type toggles
- More filters (airport, aircraft, etc.)

Tip: Keep date filters broad while reviewing totals, then narrow for reports.

## 6. Check Totals and Analyses

- `Totals`: consolidated time and counters for selected filters.
- `Analyses`: grouped views (by family, type, aircraft, etc.).

## 7. Generate PDF Reports

1. Open `Reports`.
2. Choose template (EASA or Standard, or custom template).
3. Review options (date range, include previous values).
4. Tap `Generate PDF`.
5. Choose file name/location and save.

## 8. Local Device Sync (LAN)

SimpleLog can transfer database directly between devices on your local network.

1. Connect both devices to the same Wi‑Fi/LAN.
2. Open Database Sync.
3. Select target device.
4. Choose:
   - Pull from device
   - Send to device

## 9. Backup Strategy (Recommended)

- Keep periodic copies of your database file.
- Export critical reports (monthly/yearly) to PDF.
- Before major changes/imports, create a backup.

## 10. Notes

- Data is local-first: you keep full ownership.
- No forced remote server storage.
- Project is open source under GPL v3.0.
