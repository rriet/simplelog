# SimpleLog

**SimpleLog** is a pilot logbook app for professional and private aviators.

Designed by an airline pilot, it is built to reduce typing, speed up entries,
and keep your records accurate.

Enter the essentials, press **Calculate**, review, and save.

## Why SimpleLog

Most logbooks are data-heavy and slow in real operations.  
SimpleLog focuses on a practical cockpit-to-logbook workflow:

1. Enter only core inputs:
   - Date
   - Departure airport/time
   - Arrival airport/time
2. Let the app calculate:
   - Night
   - IFR
   - PIC / SIC
   - and more
3. Verify and save in seconds

## Feature Highlights

- Free forever and open source
- Automatic flight and duty calculations
- Local-first storage with full user ownership
- No server required for your logbook data
- Database transfer between devices, even offline
- Share one database across machines via your cloud folder
- PDF report generation (EASA and Standard/Jeppesen formats)
- Fast totals and analysis
- Visited airports map view
- Multi-platform support:
  - Windows
  - macOS
  - Linux
  - iOS
  - Android

## Privacy and Data Ownership

SimpleLog follows a **your-data-is-yours** model:

- Data is stored locally
- No mandatory cloud account
- No forced remote storage
- You control backups, sync, and portability
